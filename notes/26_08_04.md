## 環境設定

建立 `.env` 與 `.env.example`。

`.env` 放自己的本機設定，不要提交到 GitHub。

`.env.example` 放欄位範例，方便其他人知道需要哪些設定。

## Maven 依賴

在 `pom.xml` 加入資料庫相關依賴：

- Spring Data JPA
- MySQL Connector/J
- Spring Boot Flyway
- Flyway MySQL

# 設定db連線
spring.datasource.url=${DB_URL:jdbc:mysql://localhost:${DB_PORT:3306}/${DB_NAME}?allowPublicKeyRetrieval=true&useSSL=false&serverTimezone=Asia/Taipei}
spring.datasource.username=${DB_USERNAME}
spring.datasource.password=${DB_PASSWORD}

# 1. 徹底關閉 Flyway 的啟動驗證
spring.flyway.validate-on-migrate=false

# 2. 讓 Hibernate 在啟動時，發現沒表格就自動幫你精準建表 (把原先的 validate 改成 update)
spring.jpa.hibernate.ddl-auto=update

# 啟用 Flyway , Spring Boot 啟動時會自動跑 migration
spring.flyway.enabled=true
spring.flyway.out-of-order=true
# 指定 migration SQL 放在哪裡
spring.flyway.locations=classpath:db/migration,classpath:db/seeder
spring.flyway.baseline-on-migrate=true
